# বাজার দর / BazarDor 🛍️

**BazarDor (বাজার দর)** is a modern, full-stack e-commerce and marketplace application designed to deliver a seamless shopping experience for buyers and sellers. It features full authentication workflows, interactive product management, dynamic updates, and a responsive design tailored for performance across all devices.

🔗 **Live Application:** https://bazardor-blue.vercel.app

---

## 🛠️ Technologies Used

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** MongoDB (via official MongoDB Driver)
- **Authentication:** Better Auth (Supports Email/Password, Google OAuth, and GitHub OAuth)
- **Deployment & Hosting:** Vercel

---

## ✨ Key Features

1. **Multi-Method Authentication & Session Syncing**
   - Secure sign-up and sign-in functionality powered by Better Auth.
   - Supports Email/Password authentication as well as one-click Social Logins (Google & GitHub).

2. **User Profile Management**
   - Interactive user profile dashboard allowing members to view and update account information in real-time.

3. **Dynamic Marketplace & Product Management**
   - Streamlined browsing and listing capabilities designed for high responsiveness and fast page loads.

4. **Fully Responsive & Modern UI**
   - Beautifully styled user interface built with Tailwind CSS, supporting seamless navigation across mobile, tablet, and desktop screens.

5. **Cloud Infrastructure & Serverless Integration**
   - Hosted on Vercel with automated continuous integration (CI/CD) pipeline linked directly to GitHub, utilizing serverless API routes connected to MongoDB Atlas.
